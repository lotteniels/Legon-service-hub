# Balme Service Optimizer

Group project repository. Folder structure is mapped to team pod assignments.
See `report/individual-contributions.md` for who owns what.

## Pods
- Database and Data
- Linear Structures
- Priority Structures
- Tree Structures
- Graphs and Optimization
- Searching, Sorting, and Testing
- Integration
- Report

## Getting started
1. Clone the repo
2. Each pod works inside its assigned folder (see comments in each file)
3. Open a pull request when a piece is ready for review
